Privacy Policy — Comfort Core

Last updated: September 2026

This privacy policy covers the personal-use application ("FRIDAY") built by the operator of the Comfort Core Pinterest account for their own internal use, connecting to the Pinterest API (v5).

What this app does

FRIDAY reads Pinterest analytics data (board performance, pin performance, impressions, clicks, saves) belonging solely to the Comfort Core Pinterest account, for the sole purpose of the account owner's own personal business analysis. It does not access, collect, or process data belonging to any other Pinterest user or account.

Data collected

Only analytics data about the Comfort Core account itself, accessed via the Pinterest API with the account owner's own authorization. No data from other Pinterest users or accounts is collected, stored, or processed.

Data storage

Collected analytics data is stored privately in a Firebase/Firestore database controlled solely by the account owner. It is not shared with, sold to, or accessible by any third party.

Data retention and deletion

Data is retained only as long as needed for the account owner's own analysis and can be deleted at any time at the account owner's discretion.

Contact

For questions about this policy, contact the account owner via the Comfort Core Pinterest account: pinterest.com/ComfortCore
